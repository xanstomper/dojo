## Quickstart
```
git clone https://github.com/xanstomper/dojo && cd dojo
python3 scripts/dojo.py catalog
dojo teach --class boundary
python3 scripts/dojo.py build --class HARVEST --port 8801
```

`catalog` · `build --class C --port P` · `teach --class C` · `verify`
